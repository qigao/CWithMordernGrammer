# English Edition

This directory contains the English edition of *C with Modern Grammar*.

Chapter files use stable sequence identifiers:

```text
ch-01.md
...
ch-15.md
```

The chapter title lives in each file's H1. The filename records publication order only, so title edits do not require file renames.

The English edition follows the Chinese technical content faithfully. C code, Mermaid diagrams, API identifiers, theorem names, and pinned source snapshots are preserved unless a prose comment itself needs translation.
